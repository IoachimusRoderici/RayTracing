Ray Types

RayTracing.AbstractRay — Type
abstract type AbstractRay{ND, T <: Real}

Represents a ray in ND dimensions that uses the type T for numeric calculations.

All rays have a position and a direction, and each concrete type may carry additional information.

source
RayTracing.BasicRay — Type
BasicRay{ND, T} <: AbstractRay{ND, T}

A basic implementation of a ray in ND dimensions with arithmetic type T.

Only stores a current position and a direction.

source
RayTracing.BasicRay — Method
BasicRay{ND, T}(pos, dir) where {ND, T}
BasicRay(pos, dir)

Construct a BasicRay{ND, T} with position pos and direction dir.

With the second signature, ND and T are determined automatically from the arguments.

The direction is normalized before costruction.

Both arguments should be vectors of length ND and element type T. Both are copied so that later changes to the objects passed as arguments don't affect the constructed ray.

Ray Sources

RayTracing.BackwardCameraRays — Type
BackwardCameraRays{T} <: AbstractMatrix{BasicRay{3, T}}

A rectangular grid of rays starting from a single point.

If used for backward ray tracing, each ray represents a pixel on a camera.

The rays are of type BasicRay{3,T}, and they are evaluated lazily on each call to getindex.

source
RayTracing.BackwardCameraRays — Method
BackwardCameraRays{T}(; kwargs...)

Construct BackwardCameraRays{T} from keyword arguments describing the camera as in Wikipedia: Calculate rays for rectangular viewport.

Keyword arguments:

  • origin: The point where the camera is located.
  • dir: The direction the camera is pointing in. Can't be used together with target.
  • target: A point the camera is pointing to. Can't be used together with dir.
  • up: The "up" direction of the camera (controls the rotation of the camera, can be used together with roll). Defaults to [0, 0, 1].
  • roll: Angle of rotation of the camera around dir, measured with respect to the up direction. Defaults to 0, meaning no rotation.
  • horizontal_aperture: The angle of aperture of the horizontal dimension of the image (in radians). The angle of aperture for the vertical dimension is determined by the aspect ratio given by image_size.
  • size: The size of the image, in pixels. Must be a (height, width) tuple.

Reflection Modes

RayTracing.ReflectionMode — Type
abstract type ReflectionMode

Abstract type to describe the way that rays bounce (reflect) on a surface.

Objects of this type, when passed to reflect!, determine how the ray is mutated (i.e. how a new direction is chosen, and what other data is mutated).

source
RayTracing.reflect! — Function
reflect!(ray::AbstractRay, mode::ReflectionMode, geometric_data, material_data)

Reflect ray on the surface described by mode, geometric_data, and material_data.

The type and meaning of geometric_data and material_data is defined by each type of ReflectionMode.

source
RayTracing.CombinedReflectionModes — Type
CombinedReflectionModes{Modes <: Tuple{Vararg{ReflectionMode}}} <: ReflectionMode

A ReflectionMode that combines the effects of different reflection modes.

Calling reflect! with this mode results in one call to reflect! with each contained mode.

Example

julia> struct Mode1 <: RayTracing.ReflectionMode end

julia> struct Mode2 <: RayTracing.ReflectionMode end

julia> RayTracing.reflect!(ray, mode::Mode1, geometric_data, material_data) = println(material_data)

julia> RayTracing.reflect!(ray, mode::Mode2, geometric_data, material_data) = println(geometric_data)

julia> combined_mode = CombinedReflectionModes(Mode1(), Mode2())
CombinedReflectionModes{Tuple{Mode1, Mode2}}((Mode1(), Mode2()))

julia> reflect!(:some_ray, combined_mode, "some geometric data", "some material data")
some material data
some geometric data
source
RayTracing.SpecularReflection — Type
SpecularReflection <: ReflectionMode

This ReflectionMode inverts rays with respect to a surface, mutating only the ray's direction.

source
RayTracing.SetMaterialData — Type
SetMaterialData <: ReflectionMode

A ReflectionMode that sets the ray's data to the material data passed to reflect!.

This reflection mode should be used with RayWithMutableData or other ray type implementing a data! method.

Example

julia> ray = RayWithMutableData([0,0,0.], [1,1,1.], 5);

julia> data(ray)
5

julia> reflect!(ray, SetMaterialData(), 0, 10);

julia> data(ray)
10
source
RayTracing.MaterialDataOperation — Type
MaterialDataOperation <: ReflectionMode

A ReflectionMode that applies some arbitrary operation between the ray's data and the material data passed to reflect!.

The result of the operation is set as the ray's data with data! (see RayWithMutableData).

Example

julia> ray = RayWithMutableData([0,0,0.], [1,1,1.], 5);

julia> data(ray)
5

julia> reflect!(ray, MaterialDataOperation(+), 0, 10);

julia> data(ray)
15

RayTracing.next_intersection — Function
next_intersection(ray, scene::AbstractScene) -> distance, surface_id
next_intersection(ray, scene::SceneGeometry) -> distance, surface_id

Calculate the next intersection between ray and any object from scene.

Return the distance to the intersection and an id of the corresponding surface. The type and meaning of the id is defined by the conrete type of scene.

If there are no intersections, the returned distance is infinity and the surface id is unspecified.

Tracing Interface

RayTracing.step! — Method
step!(ray, scene)

Advance ray on scene by one step.

This involves finding the next intersection, advancing, and reflecting.

Return :ok if the step was completed, :no_intersection if there are no intersections, or any other Symbol if the step cannot be completed for other reasons.

source
RayTracing.trace! — Method
trace!(ray, scene; kwargs...)

Trace a ray on a scene.

The ray is evolved by step!ing until there are no more intersections, or an ending condition is met.

Ending conditions are specified by keyword arguments. The default values are such that tracing only stops when there are no more intersections.

The return value is a Symbol indicating why tracing stopped. Possible values are:

  • :max_steps: The number of steps reached the value of the max_steps keyword argument.
  • :ray_end_condition: The function passed to the keyword argument ray_end_condition evaluated to true.
  • Any Symbol other that :ok returned by step!.

Keyword Arguments

  • max_steps: Stop tracing after this number of steps. Defaults to Inf.
  • ray_end_condition: A function that takes a ray and returns a boolean. Stop tracing when the return value is true. Defaults to Returns(false).
